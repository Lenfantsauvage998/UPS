Proyecto Node.js con Express y HTML Estático
Este es un proyecto básico que utiliza Node.js con el framework Express para servir un archivo HTML estático (index.html). Ideal como plantilla para comenzar proyectos web simples o como punto de partida para aplicaciones más complejas.

1. npm install
2. npm run dev 

Antes de comenzar, asegúrate de tener instalado lo siguiente:

Node.js y npm (versión recomendada: LTS)
